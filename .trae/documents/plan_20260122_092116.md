# Git提交和推送计划

## 1. 不要取消暂存大模型文件

* 不要取消暂存 `checkpoints_latent_simple2full/checkpoint.70000.pt` (182M)

* 不要取消暂存 `models/autoencoder_epoch273.pt` (80M)

* 这两个是特殊的！ 

## 2. 添加重要文件到暂存区

### 2.1 配置文件

* 添加更新后的 `.gitattributes`、`.githooks/pre-push` 和 `.gitignore`

### 2.2 项目总结文件

* 添加 `mcx_project_summary.md`（我们刚创建的项目总结）

### 2.3 核心代码文件

* 添加所有 `.ipynb.py` 文件，这些是项目的核心代码

* 添加 `shiyu_utils/` 目录，包含项目的工具函数

* 删除shiyu\_utils / folder的git文件，这样他们作为代码被提交，而不是作为submodule

### 2.4 深度学习相关代码

* 添加 `dl_accelerated_mcx/src/models/` 目录中的模型定义文件 

* 不用了， 直接无视，`dl_accelerated_mcx 整个加入gitignore`

## 3. 提交更改

* bad exmaple：提交信息："Add project summary and core code files"

* 不对，提交信息应该尽可能全面！！

* 确保不包含任何大文件（>50M）

* 除了上面的2个.pt文件除外！！

## 4. 推送更改

* 推送到远程仓库的 `main` 分支

* 验证推送成功，不包含大文件

## 5. 后续建议

* 不考虑使用Git LFS管理大模型文件（如果需要版本控制）

* 不清理不再需要的checkpoint文件

* 确保.gitignore规则正确配置，避免意外提交除了计划之外的大文件
